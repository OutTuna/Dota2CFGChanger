fix: fix broken CI/CD and make Linux support actually work

CI/CD:
- linuxdeploy download URL was 404 (missing .AppImage suffix), and
  linuxdeploy-plugin-appimage was missing entirely for --output appimage
- add APPIMAGE_EXTRACT_AND_RUN=1 (runners have no FUSE)
- APP_VERSION is now actually passed into CMake instead of the
  hardcoded 0.0
- themes/ is now copied next to the exe in the Windows artifact and
  bundled inside the AppImage (linuxdeploy doesn't do this on its own)
- release: use --cleanup-tag so "latest" doesn't stay pinned to a
  stale commit; add concurrency and if-no-files-found: error

Runtime/threading:
- copy_config(): copy-then-rename instead of remove-then-copy, plus a
  guard against src == dst (could previously lose the config on a
  failed copy)
- scan_thread: directory_iterator no longer crashes the thread on an
  inaccessible folder
- avatar.cpp: detached fetch threads are now tracked and joined on
  shutdown (was a potential use-after-free on static globals when
  closing the app mid-fetch)
- browse_for_folder was unreachable on Linux because of a stray
  #ifdef _WIN32 around the call site -- the folder picker now works

Paths and fonts:
- add config_dir()/exe_dir(): settings and caches now live in
  %APPDATA%/~/.config instead of the current working directory
  (this was actually broken for AppImage, which mounts read-only)
- Linux font lookup now checks DejaVu/Liberation/Noto instead of only
  C:\Windows\Fonts, so Cyrillic renders correctly

Build:
- pin stb to a specific commit instead of "master" (was a
  non-reproducible build)
- disable curl's CLI/man-page build targets to speed up CI
- drop the unused imgui_demo.cpp from the build

Assets:
- drop bg_crimson.h (a 383 KB PNG baked into the binary as a byte
  array); the Crimson theme background now loads only from
  themes/bg_crimson.png, which is simpler and shrinks the binary
- deduplicate the three copies of Steam-profile XML parsing into a
  single steam_api::*, and decode HTML entities like &amp;
